最新ダイジェスト観測候補(未掲載)方式・出典JSON

過去 1 週間に AI・ローカル LLM 界隈で出た新製品・モデル・リリースのうち、公式の一次情報で確認できたものを日本語で整理しています。各項目に図解 1 枚と、2 枚構成のブリーフ(PDF / PowerPoint)を付けています。

このページの見方
一次ソース
公式発表・公式ブログ・公式 GitHub Release など、発表元が出した情報。公開日が分かるものだけを採用の根拠にしています。
公式 URL
そのキーワードの公式ページ。「リンク到達確認」は、実際に開けること(HTTP 200)を確認した日を表します。内容の正しさそのものを保証するものではありません。
話題の根拠
今週そのキーワードに言及していた GitHub・Hacker News・Reddit・Bluesky などの投稿や repo。順位付けの材料で、内容の正しさの根拠ではありません。
確認状態
一次情報確認済み公式ドキュメント等で内容を確認 / 一部確認 / 未確認自動収集のみ(下の「観測候補」に分けて掲載)
要約
要約と図解は AI が下書きし、公式の一次情報と照合したうえで掲載しています。ベンダーが発表した数字は「発表の数字」と明記し、独自には検証していません。
スコア
複数ソースでの言及の多さと新しさから算出した 0〜100 の相対値(1 位 = 100)。蓄積が 14 日分に満たない間は「上昇中」ではなく「今週の注目」と表示します。

方式・出典

収集元: Hugging Face・GitHub・Hacker News・Reddit・Bluesky・dev.to・PyPI・OpenRouter と、各社の公式フィード。X の投稿は補助情報で、採用の判断は一次情報で行っています。公式サイトを取得できなかった発表元(例: Google DeepMind・Meta AI の一部)は、その旨を取得状態に表示します。

要約・図解・ブリーフは AI が下書きしたものを、決定的な検査(スキーマ・公式 URL の許可リスト・日付の整合・変更件数の上限)と一次情報の照合に通したものです。誤りに気づいた場合は GitHub の Issue でお知らせください。
