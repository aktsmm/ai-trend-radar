AI Trend Radar (mock)

このページの見方
目的
過去 1 週間に AI・ローカル LLM 界隈で出た新製品・モデル・リリースを機械的に集め、公式の一次情報で裏取りできたものだけを順位付けして載せます。
一次ソース
公式発表・公式ブログ・公式 GitHub Release など、発表元が出した情報。公開日が分かるものだけを採用の根拠にしています。
公式 URL
そのキーワードの公式ページ。リンク先が実際に開けること(HTTP 200)を確認したものは「確認済み」と表示します。
話題の根拠
今週、そのキーワードに言及していた GitHub・Hacker News・Reddit・Bluesky などの投稿や repo。順位付けの材料で、内容の正しさの根拠ではありません。関連の薄いものが混ざることがあります。
検証状態
検証済み公式ドキュメント等で内容を確認 / 一部検証一部のみ確認 / 未検証自動収集のみで、内容は未確認
スコア
複数ソースでの言及の多さと新しさから算出した 0〜100 の相対値(1 位 = 100)。蓄積が 14 日分に満たない間は「上昇中」ではなく「今週の注目」と表示します。
X の投稿
補助情報です。採用は一次情報での裏取りで決めています。
